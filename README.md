# 打砖块 · Breakout

纯 Canvas 写的微信小游戏 / 网页小游戏，零依赖，单文件即可运行。

## 直接玩

网页版：https://huaji23.github.io/breakout/

手机、电脑都能玩：左右滑动（或移动鼠标）控制挡板，点击发球。

## 玩法

| 机制 | 说明 |
|---|---|
| 触控挡板 | 左右滑动 / 移动鼠标，挡板平滑跟随 |
| 角度控制 | 撞击点决定反弹角度，打边缘更斜 |
| 关卡递增 | 每过一关：挡板变窄、球变快、砖块变硬（空心砖要打两次） |
| 粒子特效 | 砖块碎裂爆炸 + 撞板火花 + 屏幕震动 |
| 最高分存档 | 本地持久化（wx.setStorageSync / localStorage） |
| 生死机制 | 3 条命，掉球扣命，切后台自动暂停 |

## 文件结构

```
breakout/
├─ index.html            网页版（自包含单文件，可直接双击打开）
├─ preview.html          开发用预览页（wx API 打桩，方便浏览器调试 game.js）
├─ game.js               游戏主逻辑（微信小游戏入口）
├─ game.json             小游戏配置（竖屏）
└─ project.config.json   微信开发者工具工程配置
```

## 跑成微信小游戏

1. 用微信开发者工具打开本目录
2. `project.config.json` 里的 `appid` 换成你自己的小游戏 AppID
   （游客模式 `touristappid` 只对小程序有效，小游戏必须有真实 AppID）
3. 菜单「构建发布」→ 平台选「微信小游戏」

## 技术说明

- 逻辑分辨率固定 390×宽，高度自适应；`devicePixelRatio` 参与缩放，避免模糊
- 物理用 delta-time（`dt` 上限 0.05s），掉帧时不会穿模
- 小游戏里 `wx.onTouchStart(fn)` 是**单回调注册**，注册两次会覆盖前一次——所有点击分支必须写进同一个 handler
- 网页版通过 30 行 `wx` 桩跑同一份 `game.js`，逻辑只有一份
